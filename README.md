機構介紹

「燃點真愛」於2025年正式註冊成為香港法定慈善機構 (慈善牌照編號：91/20257)，由一群義工自發組成的團體，多年來積極策劃及參與多項公益活動，並與多間合作夥伴聯乘，透過多元化的義務工作，以身體力行實踐「樂善好施」的精神，將愛與溫暖傳遞、促進社區共融。

我們並將帶領義工及青少年，以音樂會友，推動藝術文化；以行善弘愛，培養行義新力軍，推廣「用愛心傳遞溫暖，以行動回饋社會」的使命，攜手為社會燃點真愛，跨代傳承希望。

命名來源 

團體名稱取自由鄭國江老師填詞的一首歌曲《燃點真愛》。歌詞第一句「將心中愛盡變力量」，相信人人以真心待人，用愛能發出無窮力量，這是我們義工隊的最大動力，繼續發光發熱，回饋社會，造福人群。
